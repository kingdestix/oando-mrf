## Slide 5: Key Features - Workflow Management
**Complete Request Lifecycle:**

1. **Request Creation** → Workers submit material requests with line items
2. **Technical Review** → Technical Coordinator validates technical requirements
3. **Management Approval** → Assistant Manager and Area Manager approvals
4. **POD Routing** → POD Planner routes to appropriate discipline
5. **Discipline Review** → Discipline Unit and Discipline Manager review
6. **Commercial Processing** → DU manages contractor quotations
7. **Commercial Approval** → DODM approves commercial terms
8. **Material Delivery** → Track shipment and delivery
9. **Receipt Confirmation** → Requestor confirms material receipt
10. **Closure** → Request completed and archived

**Benefits:**
- Clear accountability at each stage
- No lost requests
- Complete audit trail

---

## Slide 6: Key Features - Role-Based Access Control
**9 User Roles with Specific Permissions:**

| Role | Primary Function | Access Level |
|------|-----------------|--------------|
| **Worker** | Create requests, confirm delivery | Operational |
| **Technical Coordinator** | Technical validation | Field Operations |
| **Assistant Manager** | First-level approval | Management |
| **Area Manager** | Area-specific approval (Land/Swamp/PHC) | Regional Management |
| **POD Planner** | Route requests, generate reports | Planning & Analytics |
| **Discipline Unit** | Commercial processing | Commercial Operations |
| **Discipline Manager** | Discipline approval | Discipline Management |
| **DODM** | Commercial approval | Executive |
| **Admin** | System administration | Full Access |

**Security:**
- Commercial details hidden from field personnel
- Each role sees only relevant requests
- Digital signatures for approvals

## Slide 14: How to Use - For Requestors (Workers)
**Creating a Material Request:**

1. **Login** → Access worker dashboard
2. **Click "New Request"** → Start new MRF
3. **Fill Request Details:**
   - Select asset/location
   - Choose discipline
   - Enter reason for request
   - Set criticality level
4. **Add Line Items:**
   - Material description
   - Quantity and unit
   - OEM/Model (if applicable)
   - Part number (if applicable)
5. **Submit** → Request automatically routed to Technical Coordinator

**Confirming Delivery:**
- View requests with "Material Delivery" status
- Enter received quantities
- Confirm all materials received
- Request moves to "Closed"

---

## Slide 15: How to Use - For Approvers
**Reviewing and Approving Requests:**

1. **Login** → Access approval dashboard
2. **View Pending Requests** → See requests awaiting your approval
3. **Click "Review"** → View full request details
4. **Review Information:**
   - Request details
   - Line items
   - Previous approvals
   - Attachments
5. **Take Action:**
   - **Approve** → Request moves to next stage
   - **Reject** → Return to requestor with comments
   - **Add Comments** → Provide feedback
   - **Upload Signature** → Digital signature (optional)
6. **Submit** → Action logged in audit trail

**Note:** Each role sees only requests relevant to their approval stage.
